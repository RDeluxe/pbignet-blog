How to use
this document

This is the northstar: when a new page, asset, or social card is made, it should be checkable against what's written here. It is also a specimen — this very page is built in exhale, so what you see is what you get.

Section 01

The north star

One personal index for an engineer who is also an artist — software, game art direction, and 35mm photography, filed like a printed field journal. It should feel pressed onto warm paper, instrument-precise, and unmistakably analog in a digital world.

Locked direction — RETRO Home v2

The agreed hero treatment, and the gravitational center everything else orbits:

Photo cropThe picture is cropped at its top edge by the headline and continues up through the letterforms — background-clip:text aligned to the photo plane below, so type and image read as one continuous sheet.
DitherColour ordered Bayer dither (~4 levels/channel) — riso halftone in colour. No text outline.
SurfaceWarm paper + fine grain + faint topo contour. Mono metadata, barcode, registration marks.
AccentOlive green #3D491D — the primary ink (replaces the old RETRO blue).
MotionThe home hero bakes its dither to a static PNG (calm + legible + clean in PDF). Animated dither is welcome purposefully elsewhere — see §05.

The one rule

Each page picks one ink for its furniture and type and rides it everywhere — the dot in the mark, links, the topo tint (--topo ≈ accent @ 6–7%), tags, hover, accents. Olive is the default (home); sepia carries essays and articles. Lime is a highlight only, never body or links. The furniture/type ink is never blue, and there are never two accents on one page.

One exemption: the photographic dither tone is not bound by this rule. It can be keyed to each image — a coastal frame with a blue sky may be dithered in a marine duotone on a sepia-ink article, and that is intended, not a slip. The discipline lives in the furniture and type; the photo is allowed to speak its own colour.

Section 05

Texture & light

Three procedural layers give every page its printed-sheet feel. All are generated in-browser from texture.js + dither.js — no image assets, deterministic, and tuned to sit faint behind content.

LAYER 01

Paper & grain

Warm stock + a 120px tiling film-grain tile, multiply-blended at ~0.9. Grain.apply(20).

LAYER 02

Topography

Marching-squares contour lines from seeded value noise. Fixed, behind all. Topo.mount().

LAYER 03

Vignette

A faint top-down radial darkening at the edges — the sheet-under-light cue.

LAYER 04

Dither

8×8 ordered Bayer. Ambient field or photo halftone, with optional slow boil.

Topo — recommended parameters

ParamValueEffect
coloraccent @ ~6%tints contours to the page accent (--topo)
levels14–16number of contour bands
cell24–26grid size px — bigger = smoother
scale0.0019–0.0021landform breadth (smaller = broader)
seedany intstable per page; change for a new landscape
emphasizeEvery4–5every Nth line drawn as a heavier index contour

Dither — two modes

ambient()Procedural flowing field, needs no photo. Ink dots on transparent or ink-on-paper. Use sparingly as living texture; honours reduced-motion (freezes).
photo()Dithers a filled image-slot / img.dsrc. Optional boil flips near-threshold dots. Home hero → bake to static PNG. Articles & data-viz → a gentle live boil is welcome when it carries meaning.

DITHERED ASSETS LIVE IN assets/photos/*-dither.png / *-cdither.png (colour). The hero uses arc-cdither.png.

On animating the dither

There's no blanket ban. The home hero stays static for three reasons: a boiling headline fights legibility, calm is the brand, and PDF/print only capture the pre-animation frame. Elsewhere it's encouraged — a slow boil on an article photo or a live ambient() field behind a data-viz can be lovely. The rule is purpose + restraint: animate when it means something, keep it slow, and always honour prefers-reduced-motion (the engine already freezes there).

Use with intent

Furniture is punctuation, not wallpaper. A barcode belongs once — at the foot of a page or publication — never stamped on every image or card. Registration marks pin the page corners (and the odd framed plate), not every element. If a mark isn't doing a job, cut it.

Section 07

Components

The reusable blocks — one file each in assets/components/, imported by paper.css — shared across pages. Live specimens below — these are the real classes.

Plate — .plate (grille empruntée)

PLATE

The static presentation box. The frame is four grid lines that darken and run past the corners (#) — drawn on the sheet, not laid over it — with an ultra-light grid whose cell = the body line-height (24 px), so text sits ON the squares (this very box). The grid is earned: keep it only when the content holds the rhythm — text, and blocks whose heights & vertical margins are multiples of the cell. Anything free-height (barcodes, logos, arbitrary demos) uses plain; diagram.js plates too (they draw their own dots); recessed = paper-2 panel for busy surroundings. Chart bars get solid paper tracks. Never float a photo inside a plate.

Section 08

Page anatomy

How a page is stacked, top to bottom — and the signature hero move that defines the whole site.

The hero move — photo through the type

PIERRICK
① mono spec strip — role · coords · location
② serif intro, knocked out white
③ credit line · dither method
④ barcode + ident

The photo plane is clipped at the headline's baseline; the same image fills the letterforms above via background-clip:text, aligned by JS so it reads as one continuous picture. White overlay text gets a soft shadow for legibility. This move repeats at smaller scale in .feature blocks (a single lowercase word over a dithered photo).

Article hero — art-directed per image

The home rides the photo-through-type move; the article hero is the type-on-photo variant, and it is composed image by image, not from a fixed template. Heroes are named, standardised moves — pick one per page:

simple-ditherFull-bleed photo; the top dissolves into an animated duotone dither + contours. Parameters: --post-hero-h (height), --dither-line (how far the dissolve reaches down from the top), duotone ink/paper keyed per image.
pop-colorSelective colour: one hue is kept true (the subject), everything else dithers into a dark duotone ground. Parameters: keep colour, threshold, edge softness, colour pop, ground ink/paper, focal X/Y, title X/Y. More heroes will join this family.
Dither toneKeyed to the photograph (the colour exemption above) — a marine duotone for a blue-sky coast, a warm one for low light. Tuned per frame, not locked to the page's ink.
Title placementSet by hand per image into the open negative space, with a distinct mobile placement so it never collides with the subject when the layout reflows.
Focal pointEach image declares an object-position focal point, so the crop keeps the title's open zone intact in 16:9 and portrait alike.
LegibilityThe title must rest on a dense dither field or scrim, with measured contrast ≥3:1 for large text at every breakpoint. Verify, don't assume.

Section 11

Build conventions

How a new page is wired. Everything structural lives in paper.css + assets/components/*.css + assets/*.js; a page only sets its ink tokens, inline on <html> — page <style> blocks stay empty.

File layout

assets/paper.cssTokens, reset, texture layers; @imports every component.
assets/components/*.cssOne file per component — a component's CSS lives in exactly one file.
assets/texture.jsGrain + Topo (procedural, on window).
assets/dither.jsDither.ambient / Dither.photo + Bayer matrix.
assets/image-slot.jsDrag-drop photo slots (empty-state styling in components/ImageSlot.css).
assets/photos/*Source .jpg + baked *-dither.png / *-cdither.png.

Component conventions (Aug 2026)

One file per componentA component's CSS lives in exactly one file, assets/components/<Name>.css, imported by paper.css. Page <style> blocks stay empty — if a page needs something, it is a component or a variant of one. Page ink is <html data-ink='olive'|'sepia'>, values defined in paper.css :root[data-ink]. Only runtime values (--grain, set by texture.js) may be inline.
Variants are data-*Never suffixed classes: .tag[data-accent='on'] · .rule[data-weight='thick'] · .lede[data-size='intro'|'section'] · .figure[data-width='wide'] · .frame[data-dither='on'] · .pframe[data-ratio] · footer.site[data-variant]. Legacy class variants (.plate.plain/.recessed, .btn.accent/.invert, .regmark.tl…br) predate the rule — convert on their next pass.
Spacing scale4px grid named by size (--space-2xs 4 → --space-4xl 56) plus two deliberate half-steps: --space-sm 14 / --space-ml 18, the mono-label rhythm. Tokens go in padding/margin/gap; clamp() ends and ≤6px optical nudges stay literal.

Dithered-photo pipeline

Source photo → run through the dither (colour Bayer ~4 levels/channel) → bake the result as a PNG into assets/photos/ with a -cdither suffix. Heroes use the baked PNG (static); interactive/ambient dither is reserved for secondary moments and always respects prefers-reduced-motion.

Section 12

Guardrails

The review checklist. Before anything ships, it should pass both columns.

✓ Do

  • Keep the warm-paper base + grain + faint topo on every page.
  • Ride one accent ink per page — including the dot and the topo tint.
  • Use mono for all metadata; serif for body; Anton for display only.
  • Add furniture (reg marks, barcode, index №) as sparse, purposeful seasoning.
  • Bake the home hero dither to PNG; animate dither elsewhere only with purpose + reduced-motion.
  • Set generous negative space — the calm is the point.
  • Think in components & systems, not pages — every new element is designed as a reusable part of the kit, never a one-off.

✕ Don't

  • No blue. One accent per page; no rainbow gradients.
  • No emoji, no exclamation-y marketing voice.
  • No rounded-corner "card with left accent bar" web tropes — the callout is a pinned note, the plate a grille empruntée.
  • No ⌐ corner ticks on boxes — retired. Corner crosses exist only as the tile hover signal.
  • Don't let display type carry body copy — that's serif's job.
  • No blinking dither on the home hero; no purely decorative infinite loops.
  • No barcode / reg-mark on every element — once, with purpose.
  • Don't invent new colours — use the tokens or the named inks.
