# design/od — archive du travail d'atelier Open Design

Ce que les sessions d'idéation Open Design produisent et qu'on décide de garder est
archivé ici, tel quel (le tri vers `src/` suit PIPELINE §3 — l'archive n'est pas du code).
L'atelier vivant reste le dossier projet OD (`OD_PROJECT_DIR`) ; ici c'est la trace
commitée, datée par git.

Ne pas archiver : les doublons re-sérialisés par OD (`Nom---slug.html`), les sidecars
`*.artifact.json`, les captures.
